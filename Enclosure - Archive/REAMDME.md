# Enclosure

I have marked this part as `archived` as it is not particularly fit for purpose.  I do not use it anymore, and I would recommend that you just attach the parts to flat surface (this is what i do now). It makes it a lot easier for modifying and fiddling with the setup. You can always fix that surface into a project box should you wish.

If you use any of the later versions of the script I have posted, I have removed the use of the I2C screen and the calibration button.  I have moved to a process of using Mission Planned to control the thrust stand from instead so the screen and button were no longer needed.

I kept the arming switch and LED bar though.

I am posting these files here as some people may still want to make use of them.
